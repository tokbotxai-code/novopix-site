Introduction

Docsmith turns a folder of Markdown files into a fast, searchable documentation site. The output is plain static HTML that you can host anywhere.

Installation

# install
npm install --save-dev docsmith
# create a site
npx docsmith init docs

Configuration

Settings live in a single file at the root of your project.

{
  "title": "My docs",
  "nav": ["guide", "reference"]
}

Tip. Run the build in your CI pipeline so every change to the docs is checked before it is published.
